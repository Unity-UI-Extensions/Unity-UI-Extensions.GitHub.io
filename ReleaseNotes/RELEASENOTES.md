# Release notes have moved

**Unity UI Extensions is now two packages, one ecosystem** — and each maintains its own release notes:

- **[uGUI package release notes →](/ugui/releasenotes/)** — `com.unity.uiextensions`, the original library for Unity's established UI system.
- **[UI Toolkit package release notes →](/uitoolkit/)** — `com.unity.uitoolkitextensions`, the modern companion for Unity 6's runtime UI.

Prefer a combined view of both packages? See the [full changelog](/changelog/).

> This page previously hosted the project's unified release notes. With the 3.0 relaunch the notes are maintained per package — please update your bookmarks to the links above.
